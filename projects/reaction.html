Arduino Reaction Time Game

An Arduino project

Project Overview

For my Arduino final project, I made a reaction-time game. The game uses a green LED, a red LED, a button, and a display to measure how quickly someone can react. The Arduino records the reaction time and shows the result on the display.

[VIDEO OF PROJECT WORKING]

Why I Chose This Project

I chose this project because I wanted to build something interactive instead of just having an LED turn on and off. I had already worked with LEDs and buttons, so I wanted to combine those skills with a display and make something that actually responds to the user.

Use-Case Reflection

A reaction-time device like this could be useful for athletes who want to practice and measure their reflexes. It could also be used as a simple way to compare reaction times during training.

To make my current project more useful for this, I would add multiple rounds and have the Arduino calculate the person's average reaction time. I could also add a way to save previous scores so someone could see if their reaction time changes over time.

The skill I would rely on most is wire management. If I kept developing the project, I would probably add more components, which would mean even more wires. Keeping the wires organized and making sure I know where each one goes would make it easier to build onto the project and would make it easier to code.

What I Learned / What I'd Change

In the end, this project taught me how to combine different components to make a complete interactive device. I learned how to use a seven-segment display by testing each pin and figuring out which part of the display it controlled. I also learned how to use a button as an input and connect it with the LEDs and display through my code. Building the reaction-time game helped me understand how the circuit and code work together to make the Arduino respond to what the user does. In the future, I would like to experiment with larger displays or a four-digit display so I could show larger numbers and more information.
